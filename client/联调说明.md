# 采集与推理服务联调

与采集服务分进程联调的协议和完整步骤见 [Piper XH 时间轴集成](../docs/PIPER_XH_TIMEAXIS_INTEGRATION.md)。

## 启动推理服务

```bash
cd client
# 使用 YAML 默认模式
python run_inference_service.py --config config_agilex.yaml

# 启动时指定策略（覆盖 yaml，无需改文件）
python run_inference_service.py --mode temporal_smoothing
python run_inference_service.py --mode vlash_async
python run_inference_service.py --mode rtc
python run_inference_service.py --mode legato_async

# 查看配置里登记的策略列表与说明
python run_inference_service.py --list-modes
```

## 策略配置

- 列表：`config_agilex.yaml` → `inference.available_modes`
- 默认策略：由 `inference.execution_mode` 与 `inference.async_mode` 组合决定，可被 `--mode` 覆盖
- 各策略参数：`inference.modes.<mode>`

采集进程**无需**为换策略改代码；换策略后重启本服务即可。

## 对接配置核对

| yaml 段 | 与采集一致 |
|---------|------------|
| `collector.port` | 采集 `listen_port`（9000） |
| `collector.image_topics` | 采集 `image_topics` |
| `inference_service.listen_port` | 采集 `inference_service_port`（9001） |
